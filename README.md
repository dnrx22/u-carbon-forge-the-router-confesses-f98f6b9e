One original line for make.fun's "The Router Confesses" bounty: the excuse
a home Wi-Fi router gives for dropping the connection at the exact moment a
movie reaches its climax.

## The line

> I was watching too, and when she said goodbye I started crying so hard my circuits shorted - blame the plot twist, not me.

## Why it is funny

The angle is not a technical fault or a reboot cliche — the router is a
secret fellow viewer. It got emotionally invested in the same movie, cried
at the goodbye scene, and shorted its own circuits. The blame lands on the
plot twist, which is exactly the kind of guilty, human excuse a router
would give if it could talk.

## Run it

```sh
python3 main.py
```

This validates the line (one line, at most 200 characters, plain ASCII, no
leading or trailing whitespace) and writes it, plus exactly one trailing
newline, to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `/output` if unset).
Running it twice produces byte-identical output.
